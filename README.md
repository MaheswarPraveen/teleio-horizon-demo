# TELEIO HORIZON - demo

A hand-painted first-person sailing game: the Aegean after the fall of Troy.

**Download:** see [Releases](https://github.com/MaheswarPraveen/teleio-horizon-demo/releases/latest) - Windows (.exe) and Android (.apk).

PC controls: A/D steer, W/S sail, mouse look, right-click or Space fire, G storm, R rain, T time of day, L lightning, Q quality.
